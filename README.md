# RipVIS Hugging Face setup

This folder has been simplified for working directly with the Hugging Face dataset:

- Dataset: Ikos/RipVIS
- Entry point: src/main.py

## Setup

1. Activate the virtual environment:
   - source ../.venv/bin/activate
2. Install dependencies:
   - pip install -r requirements.txt
3. Run the script:
   - python src/main.py

If the dataset requires authentication, sign in first with:

- huggingface-cli login
